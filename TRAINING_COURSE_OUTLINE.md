# Synergrowth Inspection App — Training Course Outline

---

## Programme Details

| Item | Details |
|------|---------|
| Course Title | Synergrowth Inspection App — Mobile Application Development |
| Duration | 2 days |
| Delivery Format | Hands-on workshop (face-to-face / in-house) |
| Target Audience | Software developers and technical staff |
| Prerequisites | Basic programming knowledge; laptop and Android phone required |
| Certification | Certificate of Attendance |

---

## Training Content Outline

### Day 1
- Project setup: clone repository, install dependencies, run app
- Project structure and navigation
- Modify Welcome and Selection screens
- Product and Component inspection screens
- Add new products and metadata

### Day 2
- Camera integration and image capture
- API integration
- Result screen and operator confirmation
- Theming and branding
- Building APK for deployment

---

## Learning Outcomes

Participants will be able to:
- Run and navigate the inspection app
- Modify app screens and add new data
- Integrate with backend API
- Customize branding and build deployable APK
