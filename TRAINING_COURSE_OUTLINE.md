# Synergrowth Inspection App — Training Course Outline

**For:** Human Resource Department

---

## Course Information

| Item | Details |
|------|---------|
| **Course Title** | Synergrowth Inspection App — Mobile Application Development |
| **Duration** | 2 days |
| **Delivery Format** | Hands-on workshop (participants clone the app and learn by modifying code) |
| **Target Audience** | Software developers and technical staff who will maintain or extend the mobile app |
| **Prerequisites** | Basic programming knowledge; participants need a laptop and Android phone |

---

## Course Scope

This training covers the **mobile application only** (Expo / React Native). The backend, database, and server setup are covered by a separate training session.

---

## Learning Objectives

By the end of the course, participants will be able to:

- Run the inspection app on their device and understand the full workflow
- Modify the app screens (Welcome, Selection, Product, Component, Camera, Result)
- Add new products, production lines, and inspection components
- Understand how the app communicates with the backend API
- Customize branding, colors, and layout
- Build an installable APK for deployment

---

## Day 1 Overview

- Clone the project and run the app
- Understand project structure and how screens connect
- Modify the Welcome and Selection screens
- Work with the Product and Component inspection screens
- Add new products and metadata

---

## Day 2 Overview

- Camera integration and image capture
- API integration (how the app talks to the backend)
- Result screen and operator confirmation flow
- Theming and branding customization
- Building the APK for deployment

---

## Participant Requirements

- Laptop (Windows, macOS, or Linux)
- Android phone with Expo Go app installed
- Node.js, Git, and VS Code or Cursor (instructions provided before training)
- Internet access during the course
